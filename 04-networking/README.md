## Why Networking Matters in Cybersecurity

Cybersecurity depends heavily on understanding how devices communicate over networks.

Networking knowledge helps me understand:

- How systems find each other
- How IP and MAC addresses are used
- How domain names are resolved
- How devices communicate inside a local network
- How open ports and services can be identified
- How network traffic can be inspected
- How suspicious communication can be investigated
