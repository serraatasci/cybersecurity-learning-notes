# Windows System Tools and Management

This page contains my notes on important Windows system administration and monitoring tools.

---

## MSConfig — System Configuration

MSConfig is a Windows utility used for system startup and troubleshooting.

It can be opened with:

`msconfig`

MSConfig provides access to several configuration areas related to:

- Startup behavior
- Boot options
- Services
- Troubleshooting
- System tools

---

## Why MSConfig Is Useful

MSConfig can help troubleshoot Windows startup problems.

For example, it can be useful when:

- A service causes startup problems
- Windows behaves unexpectedly after boot
- Troubleshooting requires limiting startup components

It is mainly a diagnostic and troubleshooting tool.

---

# Advanced System Settings

Windows provides an Advanced System Settings section for configuring important system behavior.

It can include settings related to:

- Performance
- User profiles
- Startup and recovery
- Environment variables

---

## Performance Settings

Performance settings control how Windows manages visual effects and system resources.

Examples may include:

- Animations
- Visual effects
- Processor scheduling
- Virtual memory

---

# Virtual Memory and Pagefile

Windows can use part of the disk as additional memory when physical RAM is insufficient.

This is called virtual memory.

The file used for this purpose is commonly known as:

`pagefile.sys`

The pagefile can help the operating system continue working when RAM usage becomes high.

---

## Why the Pagefile Matters

The pagefile can be useful for:

- Supporting memory management
- Handling high memory usage
- Supporting crash dump creation

However, disk storage is much slower than physical RAM.

---

# Startup and Recovery

The Startup and Recovery section includes settings related to:

- System startup
- Operating system selection
- System failure behavior
- Crash dump creation

---

## Crash Dumps

When Windows experiences a serious system failure, it can create a crash dump.

A crash dump contains information about the state of the system at the time of the failure.

Crash dumps can help with:

- Troubleshooting
- Debugging
- Malware analysis
- Digital forensics

---

# Computer Management

Computer Management is a Windows administrative console that combines several system management tools.

It can be opened with:

`compmgmt.msc`

It provides access to tools such as:

- Task Scheduler
- Event Viewer
- Shared Folders
- Local Users and Groups
- Performance
- Device Manager
- Disk Management
- Services and Applications

---

# Task Scheduler

Task Scheduler allows Windows to automatically execute programs or commands based on defined triggers.

Examples of triggers include:

- At system startup
- At user logon
- At a specific time
- When a specific event occurs

---

## Task Scheduler Components

A scheduled task commonly includes:

### Trigger

Defines when the task starts.

### Action

Defines what the task does.

### Conditions

Additional requirements that must be met.

### Settings

Controls how the task behaves.

---

## Why Task Scheduler Matters in Cybersecurity

Task Scheduler is useful for legitimate automation.

It can also be important during security investigations because attackers may abuse scheduled tasks for persistence.

A suspicious scheduled task may automatically start malicious software after:

- Reboot
- User login
- A specific time interval

Because of this, scheduled tasks are often checked during incident investigations.

---

# Event Viewer

Event Viewer is one of the most important Windows monitoring tools.

It can be opened with:

`eventvwr.msc`

Windows records many system activities as events.

These events can be reviewed using Event Viewer.

---

## Main Windows Logs

Important log categories include:

- Application
- Security
- Setup
- System

---

## Application Log

Contains events generated by applications.

These may include:

- Application errors
- Warnings
- Informational events

---

## Security Log

Contains security-related events.

Examples can include:

- Login events
- Authentication failures
- Account activity
- Security policy events

The Security log is especially important in cybersecurity investigations.

---

## System Log

Contains events generated by Windows system components.

Examples include:

- Driver problems
- Service failures
- Hardware-related issues
- Operating system events

---

## Event Levels

Events may have levels such as:

- Information
- Warning
- Error
- Critical

These levels help indicate the severity of an event.

---

## Event IDs

Windows events have Event IDs.

An Event ID helps identify the type of activity that occurred.

During investigations, analysts can use Event IDs to search for particular actions or security events.

---

# Shared Folders

Computer Management includes a Shared Folders section.

This area can show:

- Shares
- Sessions
- Open Files

---

## Shares

Displays folders and resources shared over the network.

---

## Sessions

Shows users currently connected to shared resources.

---

## Open Files

Shows files that remote users currently have open through network shares.

---

## Why Shared Folders Matter

Unexpected shares or sessions can indicate:

- Misconfiguration
- Unauthorized access
- Excessive permissions
- Suspicious network activity

---

# Performance Monitor

Performance Monitor is used to monitor Windows system performance.

It can be opened with:

`perfmon`

It can track system measurements over time.

These measurements are called:

`Performance Counters`

---

## Examples of Performance Counters

Performance Monitor can examine areas such as:

- CPU usage
- Memory usage
- Disk activity
- Network activity

This helps identify resource problems and unusual system behavior.

---

# Device Manager

Device Manager displays hardware devices connected to the Windows system.

It can be used to:

- View devices
- Check device status
- Update drivers
- Disable devices
- Troubleshoot hardware problems

---

## Why Device Manager Matters

Security-related use cases may include checking:

- Unexpected hardware
- Network adapters
- USB devices
- Driver problems

Drivers operate with significant system privileges, so driver security can also be important.

---

# Disk Management

Disk Management allows administrators to manage storage devices and partitions.

It can be used to:

- View disks
- Create partitions
- Delete partitions
- Format volumes
- Assign drive letters
- View storage information

---

## Disk and Volume Concepts

A physical disk can contain one or more partitions or volumes.

Example concept:

`Physical Disk`

↓

`Partitions`

↓

`Volumes`

↓

`File System`

A volume may then use a file system such as NTFS.

---

# Services

Windows services are programs that typically run in the background.

They can operate without a user directly interacting with them.

Examples include services related to:

- Networking
- Updates
- Security
- Printing
- Remote access

---

## Services Management Console

Services can be viewed with:

`services.msc`

For each service, Windows may show information such as:

- Service name
- Description
- Status
- Startup type

---

## Service Startup Types

Common startup types include:

### Automatic

Starts automatically with Windows.

### Manual

Starts when required.

### Disabled

Cannot start until re-enabled.

---

## Why Services Matter in Cybersecurity

Services often run with significant privileges.

During a security investigation, analysts may check for:

- Unknown services
- Unexpected executable paths
- Suspicious startup behavior
- Services created for persistence

---

# WMI — Windows Management Instrumentation

WMI stands for:

`Windows Management Instrumentation`

WMI provides a way to obtain and manage information about Windows systems.

It can be used by:

- Administrators
- Scripts
- Management tools
- Applications

WMI can provide information about:

- Hardware
- Processes
- Operating system
- Services
- Network configuration

---

## WMI and Cybersecurity

WMI is a legitimate Windows management technology.

However, because it can remotely interact with Windows systems and execute management operations, it can also be abused.

Security analysts may examine WMI activity when investigating:

- Remote administration
- Persistence
- Suspicious execution

---

# Resource Monitor — `resmon`

Resource Monitor provides detailed information about resource usage.

It can be opened with:

`resmon`

The main categories are:

- CPU
- Memory
- Disk
- Network

---

# CPU Monitoring

The CPU section can show:

- Running processes
- CPU usage
- Services related to processes

This can help identify processes consuming unusual amounts of CPU.

---

# Memory Monitoring

The Memory section shows how processes are using RAM.

This can help identify:

- High memory usage
- Memory pressure
- Unusual process behavior

---

# Disk Monitoring

The Disk section displays disk activity.

It can show:

- Which processes are reading files
- Which processes are writing files
- File paths being accessed
- Disk activity levels

This can be useful during malware analysis and troubleshooting.

---

# Network Monitoring

The Network section displays network activity associated with processes.

It can show:

- Processes using the network
- Network connections
- Listening ports
- Remote addresses

This makes Resource Monitor useful when checking which programs are communicating over the network.

---

# Resource Monitor vs Task Manager

Task Manager provides a quick overview of processes and resource usage.

Resource Monitor provides more detailed information about:

- Disk activity
- Network connections
- Memory
- CPU

A simple way to remember:

`Task Manager → Quick Overview`

`Resource Monitor → Detailed Investigation`

---

# Why These Tools Matter in Cybersecurity

Windows administrative tools are useful because they provide visibility into system behavior.

They can help identify:

- Suspicious processes
- Unexpected services
- Scheduled tasks
- Login activity
- Network connections
- Shared folders
- Disk activity
- Hardware changes
- System errors

These tools are commonly useful in system administration, troubleshooting, and security investigations.

## Key Takeaway

Windows includes many built-in tools that provide visibility and control over the operating system.

A useful security mindset is:

`System Configuration + Logs + Processes + Services + Network Activity + Scheduled Tasks`

Together, these tools help administrators and security analysts understand what is happening on a Windows system.
