# Linux File System

## Common Linux Directories

/bin = Contains basic user commands and executable programs.

/sbin = Contains system binaries, mostly used by the root user or system administrators.

/dev = Contains device files related to hardware.

/etc = Contains configuration files.

/var = Contains variable files such as logs, cache files, and web server data.

/tmp = Contains temporary files.

/home = Contains user home directories.

/mnt = Used for temporarily mounted file systems.

/media = Used for removable media such as USB drives.

/srv = Contains data for services provided by the system.
