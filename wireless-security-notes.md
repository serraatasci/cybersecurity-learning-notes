# Wireless Security Notes

## Disclaimer

These notes are for educational purposes only. Wireless security practices must only be performed in authorized and controlled lab environments.

## Wireless Network Modes

Managed Mode = Used for normal Wi-Fi connection.

Monitor Mode = Allows a wireless adapter to observe wireless traffic in the air. It is commonly used in wireless security labs.

## Encryption Types

Common wireless encryption types include:
- WEP
- WPA
- WPA2

## Wireless Network Observation

In wireless security labs, tools can be used to observe:
- Network name
- BSSID
- Channel
- Encryption type
- Signal level
- Connected clients

This helps understand how wireless networks operate.

## Deauthentication Concept

Deauthentication is a wireless network concept related to disconnecting a client from an access point.

In cybersecurity learning, this concept is studied to understand:
- How wireless clients connect to access points
- How management frames work
- Why modern wireless protection mechanisms are important
- How wireless networks can be secured against disruption

Note: Deauthentication tests should only be studied in legal and authorized lab environments.

## Fake Authentication Concept

Fake authentication is a wireless security lab concept used to understand how authentication frames work in older wireless security scenarios.

This topic is useful for learning:
- Wireless authentication behavior
- Client-access point communication
- Weaknesses in outdated wireless security mechanisms

Note: This topic should only be studied in controlled and authorized cybersecurity labs.

## Packet Capture

Wireless packet capture is used in lab environments to analyze wireless traffic and understand network behavior.

Captured packets can help students learn about:
- Authentication frames
- Deauthentication frames
- Data packets
- Encryption behavior
- Client and access point communication

## Security Awareness

Studying wireless security helps understand the importance of:
- Strong WPA2/WPA3 passwords
- Updated router firmware
- Disabling outdated encryption methods
- Using secure network configurations
- Monitoring suspicious network behavior
