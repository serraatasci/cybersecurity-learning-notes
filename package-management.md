# Package Management

## APT

APT stands for Advanced Package Tool. It is used to install, update, upgrade, and remove software packages.

sudo apt update = Updates the package list.

sudo apt upgrade = Upgrades installed packages to newer versions.

apt search wireshark = Searches for packages related to Wireshark.

apt-get = Another command-line tool for working with packages. It is commonly used for installing, updating, and removing packages.
