# Networking Basics

## VPN

VPN stands for Virtual Private Network. It is used to create a secure connection between a device and a private network.

openvpn <config-file> = Connects to a VPN configuration file in lab environments.

Ctrl + C = Stops the VPN connection or stops a running terminal process.

## DNS

DNS stands for Domain Name System. It translates domain names into IP addresses.

Example:
google.com -> IP address

DNS allows users to access websites by using domain names instead of memorizing IP addresses.

## Ping

ping google.com = Sends small network requests to a target and receives replies.

It can be used to check connectivity and see the target’s IP address.

Ctrl + C = Stops the ping command.

## IP Address

An IP address identifies a device on a network.

## MAC Address

MAC stands for Media Access Control. It is a unique hardware address assigned to a network interface.

A MAC address:
- Is usually 48 bits long
- Is written in hexadecimal format
- Helps devices identify each other on a local network

Example format:
00:1A:2B:3C:4D:5E

## ARP

ARP stands for Address Resolution Protocol. It maps IP addresses to MAC addresses inside a local network.

## TCP/IP

TCP/IP is the main communication model used for data transmission across networks.
